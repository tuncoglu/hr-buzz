# Security and privacy reports

HR Buzz handles heart-rate, location and other health data, so reports about how it handles them
are welcome: a leak, an unexpected network call, a permission it does not need, or text in the
privacy policy that the code does not back up.

Email **privacy@sourdoughcalculator.uk** with what you saw and, if you can, the file and line.
Please give us a reasonable time to fix a problem before you publish it. We will say what we
found and what we changed, including when the answer is "that is a mistake in our policy text".

How the app handles data, and how to check each claim yourself, is in
[hr-buzz/DATA-HANDLING.md](hr-buzz/DATA-HANDLING.md).
